# 계좌통합 리밸런싱

여러 계좌(IRP·연금저축·ISA·위탁)의 현재 잔고를 목표 포트폴리오로 **회차별로 나눠 이동**하기 위한 한 화면 도구입니다.

- 주소: https://jacelee660303-png.github.io/rebalance-planner/
- 파일: `index.html`(본체), `xlsx.full.min.js`(엑셀 읽기·쓰기, SheetJS 0.18.5 / Apache-2.0)

## 기능
- 계좌별 보유수량·목표 비중 입력, 목표금액·조정 수량 계산
- 회차 수 1~10회 선택(균등 분할, 회차별 누적 진행률 직접 수정 가능)
- 회차별 진행률(예: 25 → 50 → 75 → 100%)에 따른 매도·매수 주문표, 체결 반영, 되돌리기, 이력
- 회차별 매도·매수 주식 수 일정표, 회차 전·후 보유 주식 수
- 보유 상태별 행 색상(계속 보유 · 정리 대상 · 신규 편입), 잔고·목표와 단계 이동에서 같은 색
- 종목별 매도 하한가·매수 상한가(조건 미충족 시 보류), 회차별 계좌 납입금, IRP 위험자산 한도 점검
- 계좌별·섹터별·ETF별 통합 요약
- 기존 엑셀 불러오기, 엑셀 내보내기, 백업 파일 저장·불러오기

## 데이터와 시세
- 잔고·목표·이력은 **사용자 브라우저(localStorage)에만** 저장됩니다. 이 저장소와 서버에는 개인 데이터가 없습니다.
- 시세는 네이버 금융의 ETF 목록·실시간 시세를 브라우저에서 직접 받습니다. 받은 스크립트는 격리된 iframe 안에서만 실행됩니다.
- 시세 조회가 실패하면 마지막 조회값을 유지하며, 종목 목록에서 수동 가격을 넣을 수 있습니다.

## 배포
저장소 Settings → Pages → Branch `main` / `(root)` 로 지정하면 됩니다. 별도 빌드나 Actions는 필요 없습니다.

계산 결과는 참고용이며 실제 주문 전 증권사 화면의 잔고·체결가를 확인하십시오.
